# Подбор методов юзабилити-тестирования

Одностраничный демонстрационный интерфейс для ВКР «Исследование методов юзабилити-тестирования веб-приложений».

## Стек

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Tabs, Tooltip, Table)

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`
